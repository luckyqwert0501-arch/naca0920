# 好日集 NANACACA － 代購管理平台

## 現況：已接上真正的 Google Sheets 後端

這一版 `data.js` 會在每次開啟頁面時，透過 `config.js` 裡設定的 Google Apps Script
網址（`NC_GAS_URL`）跟你的 Google Sheet 讀寫資料，不再只是存在瀏覽器本機。

- **後台頁面**（總覽/商品輸入/顧客入單/訂單/成本利潤/設定）：開啟時會先跟後端要
  「目前所有資料」，抓回來後才開始顯示；之後你在頁面上的每個操作（存商品、送出
  訂單、改設定…）都會立刻反映在畫面上，同時在背景把整包資料同步回 Google Sheet。
- **顧客匯款回報頁 `remit.html`**：完全獨立運作，不會載入任何後台資料，只透過
  兩個小動作跟後端溝通（讀一筆訂單金額摘要、送出一筆回報），確保顧客這頁看不到
  你的商品、其他顧客、密碼等資料。

## Code.gs 是新的一版（單一 JSON 狀態設計）

跟最早給你的版本不同，這版不再拆成 10 個關聯式分頁，而是把整包資料存成一份 JSON
放進一個叫 **State** 的分頁裡——對單人使用的系統來說更簡單、更不容易壞。

**如果你的 Google Sheet 裡還是舊版的 Code.gs，請照下面步驟更新：**

1. 打開你的 Google Sheet →「擴充功能」→「Apps Script」
2. 把編輯器裡的內容整個刪除，貼上這次附上的新版 `Code.gs`
3. 存檔（Cmd+S / Ctrl+S）
4. 右上角「部署」→「管理部署作業」→ 點你現有那組部署旁的鉛筆（編輯）圖示 →
   版本選「新版本」→ 部署。**這樣可以沿用同一個網址**，`config.js` 裡的
   `NC_GAS_URL` 不用改。

之後每次修改 Code.gs，都要重複第 4 步（新增版本）才會生效，光存檔不會讓正在
運作的網址套用新程式碼。

## 檔案總覽

- `index.html` / `products.html` / `order.html` / `orders.html` / `costs.html` /
  `reports.html` / `settings.html` — 後台頁面，都需要密碼（在設定頁設定）
- `remit.html` — 顧客匯款回報頁，無密碼，透過訂單專屬連結開啟
- `config.js` — 你的 Google Apps Script 部署網址，改後端網址只要改這一行
- `data.js` — 前端資料層／業務邏輯（成本試算、組合價、購物車、期別等）
- `nav.js` — 共用選單、密碼鎖畫面
- `style.css` — 響應式版面與視覺設計
- `Code.gs` — 貼進 Google Apps Script 的後端程式

## 已知限制

- 顧客回報匯款、跟你在後台編輯資料是「各自為政」的：為了避免顧客回報的當下被你
  後台的其他操作覆蓋掉，`Code.gs` 特別把 remittances（匯款回報）獨立處理，不會
  被後台的整包同步覆寫。但商品/訂單/設定這些仍是「整包覆寫」，如果你**同時**用
  兩台裝置編輯同一筆商品，後存檔的會覆蓋先存檔的——單人操作、依序使用不會遇到
  這個問題。
- 收據照片目前還是存在瀏覽器本機（localStorage），不會同步到 Google Sheet，檔案
  一多可能會佔滿瀏覽器儲存空間。之後如果需要，可以改成上傳到 Google Drive、只把
  連結存進資料裡。
- 網路斷線時，頁面會自動改用瀏覽器本機的備份資料顯示，但你在離線期間做的修改不會
  同步到 Google Sheet，等於只在該台裝置、該次瀏覽有效，建議還是在有網路時操作。
